# Личный кабинет АГТУ для Android

Приложение открывает `https://kabinet.astu.ru/` во встроенном Android WebView.

## Возможности

- вход в личный кабинет через защищённое HTTPS-соединение;
- сохранение cookies и состояния страницы;
- кнопка «Назад» для навигации по истории сайта;
- выбор файлов из памяти телефона;
- внешние ссылки открываются системным браузером;
- иконка приложения в стиле АГТУ.

## Сборка

Откройте проект в Android Studio и выполните `Build > Build APK(s)`. Для сборки нужен Android SDK с API 35 и JDK 17.

APK после сборки будет находиться в `app/build/outputs/apk/debug/app-debug.apk`.

## Сборка через GitHub

В проект уже добавлен workflow `.github/workflows/build.yml`.

1. Создайте новый пустой репозиторий на https://github.com/new.
2. Назовите его, например, `AGTU-Kabinet`.
3. На странице репозитория выберите `Add file > Upload files`.
4. Перетащите в окно все файлы и папки из этой директории, включая `.github`.
5. Нажмите `Commit changes`.
6. Откройте вкладку `Actions` и выберите запуск `Build APK`.
7. Откройте завершившийся запуск и скачайте артефакт `AGTU-Kabinet-debug-apk`.
8. Распакуйте скачанный ZIP. Внутри будет файл `app-debug.apk`.

После каждого push в ветку `main` или `master` GitHub будет собирать новый APK автоматически. Workflow можно запустить вручную через `Actions > Build APK > Run workflow`.
